This spec states WHAT the CSV import does and its acceptance criteria, and leaves
implementation to the plan — it does not prescribe file layouts or code structure.
It traces to requirement FR-001, and where it depends on the datastore or stack it
cites that decision as an external authority instead of re-deciding it.
